## 🚀 GitHub Pages Deployment Steps

1. Create a folder named `portfolio`.
2. Add `index.html`, `style.css`, and `script.js`.
3. Open the project folder in VS Code.
4. Develop and test the website in a browser.
5. Create a new public GitHub repository named `portfolio`.
6. Open the terminal inside the project folder.
7. Run:
   ```bash
   git init
   git add .
   git commit -m "Create portfolio website"
   git branch -M main
   git remote add origin https://github.com/Yash-Maithani/portfolio.git
   git push -u origin main
   ```
8. Open the repository on GitHub.
9. Go to **Settings → Pages**.
10. Under **Build and deployment**, select **Deploy from a branch**.
11. Select the `main` branch.
12. Select `/(root)` as the folder.
13. Click **Save**.
14. Wait for GitHub Pages to deploy the website.
15. Open: `https://Yash-Maithani.github.io/portfolio/`
16. Test the live website.
17. Submit the GitHub repository link, live website link, and step-by-step PDF.
