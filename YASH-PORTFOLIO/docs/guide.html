05 Complete 17-Step GitHub Deployment Process

Follow this exact sequence to build, push, deploy, and verify your portfolio on GitHub Pages:

1-4 Phase 1: Local Setup & Testing
  1. Step 1: Create a folder named portfolio.
  2. Step 2: Add index.html, style.css and script.js.
  3. Step 3: Open the project folder in VS Code.
  4. Step 4: Develop and test the website in a browser.
5-7 Phase 2: Repository & Git Push
  1. Step 5: Create a new public GitHub repository named portfolio.
  2. Step 6: Open the terminal inside the project folder.
  3. Step 7: Run the terminal commands:
git init
git add .
git commit -m "Create portfolio website"
git branch -M main
git remote add origin https://github.com/Yash-Maithani/portfolio.git
git push -u origin main
Alternative Web Upload: If Git CLI is not installed, click "uploading an existing file" on your new GitHub repo page, drag & drop all files, and click Commit changes.
8-14 Phase 3: Activating GitHub Pages
  1. Step 8: Open the repository on GitHub: https://github.com/Yash-Maithani/portfolio.
  2. Step 9: Go to Settings → Pages in the repository tabs.
  3. Step 10: Under Build and deployment, select Deploy from a branch.
  4. Step 11: Select the main branch from the dropdown.
  5. Step 12: Select /(root) as the folder.
  6. Step 13: Click Save.
  7. Step 14: Wait for GitHub Pages to deploy the website (approx. 60–90 seconds).
15-17 Phase 4: Live Verification & Final Submission
  1. Step 15: Open your live website URL: https://Yash-Maithani.github.io/portfolio/.
  2. Step 16: Test the live website (navigation, dark/light theme, mobile layout).

AP Appendix: Troubleshooting & Frequently Asked Questions

! Common Deployment Questions
  • Why is my site showing 404 Not Found? GitHub Pages takes 1–3 minutes to build on first deployment. Check the Actions tab in your repository to confirm the build workflow has finished with a green checkmark. Also confirm that the file is strictly named lowercase index.html.
  • Why isn't CSS or JS loading? Ensure all paths in index.html are relative (e.g. style.css and script.js, not absolute local drive paths like C:/...).
  • How do I update my portfolio later? Simply edit your files, then run git add ., git commit -m "Update portfolio", and git push. GitHub Pages will automatically deploy the changes within 60 seconds!
